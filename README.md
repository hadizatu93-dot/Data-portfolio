Week 1 Impact Lab: eHealth Africa
The Problem
eHealth Africa works to strengthen health systems in Nigeria through data and technology. A key challenge is that health data is often fragmented, late, or incomplete — making it hard for decision-makers to know where vaccines, staff, or supplies are needed most.
 My Analysis
In this lab, I explored how data can improve health delivery:
- Tracked where health facilities report late or missing data
- Identified gaps in service delivery by location
- Showed how clean, timely data helps target interventions
Tools Used
- Excel / Google Sheets for cleaning and analysis
- GitHub for portfolio and version control
 Key Insight
Good data is not just numbers — it helps save lives by making sure the right help reaches the right community at the right time.
Next Steps
- Build a simple dashboard for facility reporting
- Practice more data cleaning and visualization in Week 2
